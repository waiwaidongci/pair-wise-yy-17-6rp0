# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 高值处置闭环

巡测上报 CO2 后自动判定，不再只是标记异常：

- **自动开单**：读数高出样点基准 150ppm 时开立处置单，样点转重点保护。
- **读数归并**：同一样点有未关闭处置单时，后续读数归到原单；存储层串行化读写，两人同时上报不丢数。
- **入口停发**：读数高超 150ppm 且洞内有人时，该洞穴入口暂停签发进场许可。
- **通风复测**：须由非处置组成员完成，两次复测间隔 ≥30 分钟且都回到基准 80ppm 以内，处置单自动关闭、许可恢复。
- **更正重判**：基准 CO2 或原读数更正后，未关闭单按新值重判（停发、关闭条件同步重算）；已关闭旧单留档不动。

判定规则（阈值、复测间隔、处置组名单）在 `project.config.js` 的 `rules` 中配置。

## 分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 判定 | `src/judgment.js` | 开单/归并/停发/复测关闭/重判，纯函数不碰 IO |
| 存储 | `src/store.js` | `db.json` 读写，mutate 队列串行化防并发丢数 |
| 页面 | `public/` | 看板、高值处置、进场许可、样点、巡测视图 |

`server.js` 只做 HTTP 接线。关键接口：`POST /api/readings`（上报读数）、`POST /api/incidents/:id/retests`（通风复测）、`POST /api/permits`（签发许可）、`PATCH /api/sites/:id` / `PATCH /api/surveys/:id`（更正后联动重判）。
