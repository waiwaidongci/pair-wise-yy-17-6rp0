# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## CO2 高值处置闭环

巡测上报 CO2 后由判定层自动处理，不再只是标记异常：

- **开单与归单**：读数高出基准 150ppm 自动开立处置单；同一样点有未关闭单时，后报读数归到原单。所有写库走串行事务，两人同时上报也不丢数。
- **停发许可**：读数高出基准 150ppm 且洞内有人时，入口停发许可（样点「入口许可」变为停发）。
- **通风复测**：须由非处置组成员登记；两次复测都回到基准 80ppm 以内且间隔满 30 分钟，才关闭处置并恢复许可（满足条件自动关闭，也可手动关闭，条件不满足会被拦截）。
- **更正重判**：基准 CO2 或原读数更正后，未关闭单按新值重判（许可、峰值、复测合格线同步重算），更正前的判定快照留在 `revisions` 留档。

## 分层

- `lib/judgment.js`：判定层，阈值与业务规则（150ppm / 80ppm / 30 分钟），不碰存储与页面。
- `lib/store.js`：存储层，db.json 读写与串行事务。
- `server.js`：路由，把判定与存储接起来。
- `public/`：页面层，处置单视图、复测表单、更正入口。

## 接口

- `POST /api/surveys`：登记巡测，自动高值判定、归单、许可联动。
- `POST /api/incidents/:id/recheck`：登记通风复测 `{ tester, co2, at? }`。
- `POST /api/incidents/:id/close`：手动关闭处置（校验复测条件）。
- `PATCH /api/sites/:id` / `PATCH /api/surveys/:id`：更正基准或原读数，触发未关闭单重判。

## 测试

```bash
npm test
```
